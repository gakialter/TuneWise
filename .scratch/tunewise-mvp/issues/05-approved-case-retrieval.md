# 05 — TW-05 生成并检索兼容的 APPROVED-only 相似案例

**What to build:** 提供从允许训练分区生成预置 `APPROVED` 案例和结构化索引的可重复命令，并让工程师在诊断页稳定看到 3 个兼容已审核案例。PENDING、测试、验证、盲测和演示来源从资产生成、索引构建到查询均被阻断。

**Blocked by:** 04 — TW-04 输出 Top-3 根因、证据充足度与结构化解释。

**Status:** ready-for-agent

## 规格追踪

- 规格章节：8.3–8.5、13、19.1、22、23.1–23.4、24.5。
- AC：AC-D4-02、AC-D5-05、AC-D5-06、AC-D6-06。
- HG：HG-04、HG-07、HG-08、HG-09、HG-10、HG-15、HG-16。

## Acceptance criteria

- [ ] 提供可重复执行的命令，只从允许训练分区生成预置 APPROVED 案例、标准化器和结构化 KNN 索引。
- [ ] 每个案例和索引记录来源 Batch、分区、station/product 兼容信息、版本和内容哈希；非训练来源无法进入生成结果。
- [ ] 索引构建强制 `status = APPROVED`，查询时再次强制同一过滤，形成双重防护。
- [ ] 检索采用允许案例数据拟合的标准化器、固定特征顺序、标准化欧氏距离、两阶段候选池以及距离后 `case_id` 的稳定 tie-breaker。
- [ ] 距离维度不含 FaultTruth、审核根因、动作、结果、batch_id 或 case_id；审核根因只用于候选池筛选和展示。
- [ ] 返回 case_id、距离/相似度、主要差异、审核根因、历史动作、历史模拟结果和适用条件；不足时返回 `NO_RELEVANT_CASE_AVAILABLE`，不得用非法案例补足。
- [ ] PENDING_REVIEW、验证/测试/盲测/演示批次及不兼容工站或产品均不会进入索引或结果。
- [ ] 使用同一资产重建索引后，查询结果顺序、索引版本和业务哈希保持稳定。
- [ ] 查询期间 SimulatorGateway、大模型、在线 Embedding、向量数据库和网络调用数均为零。

## 本票不包含

案例审核、PENDING→APPROVED、在线学习、参数候选和最终 Recall 门槛验收。

## 独立验证

重复生成案例资产和重建索引，比较来源清单、版本、哈希及稳定排序；向测试输入混入 PENDING、跨分区、演示、测试和不兼容案例，确认生成、索引与查询三层均拒绝污染。
