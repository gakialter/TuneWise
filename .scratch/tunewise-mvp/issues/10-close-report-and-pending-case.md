# 10 — TW-10 关闭任务、生成报告并提交 PENDING_REVIEW 案例

**What to build:** 让 AA 工艺工程师在有效回放后关闭任务、生成引用不可变结果的复盘报告、导出材料并提交待审核案例；待审核列表立即显示新记录，但该记录不能进入检索、荐参或训练。

**Blocked by:** 09 — TW-09 安全处理回放拒绝、异常恢复、并发与幂等。

**Status:** ready-for-agent

## 规格追踪

- 规格章节：6、7、18.7、19、20、22、23.3–23.4。
- AC：AC-D2-04、AC-D2-05、AC-D3-04、AC-D7-07。
- HG：HG-04、HG-07、HG-10、HG-14；本票建立实际报告、导出和新 PENDING 路径，跨模块最终放行由 TW-12 承担。

## Acceptance criteria

- [ ] 未 `REPLAYED` 的任务不能关闭；合法关闭生成 Report 引用并进入 `CLOSED`。
- [ ] 报告只引用 Task、DiagnosticResult、ConfirmedPlan 和不可变 ReplayResult，不改写、重算或替换回放指标与状态。
- [ ] 报告和实际导出材料显示完整回放免责声明，且不包含真实产线、真实良率、最优参数或真实因果声明。
- [ ] 人工确认、回放启动/拒绝/失败/完成、关闭、报告生成和案例提交形成追加式最小审计链。
- [ ] AuditEvent 包含固定身份、时间、动作、对象引用/哈希、版本和结果/拒绝原因，不记录 FaultTruth、隐藏场景、系数或敏感环境信息。
- [ ] 仅 `CLOSED` 任务可提交案例；提交创建 `PENDING_REVIEW` Case 并进入 `CASE_SUBMITTED`。
- [ ] 重复提交同一任务幂等返回既有待审核案例，不创建重复条目。
- [ ] 新提交案例出现在待审核列表，但 APPROVED 索引、案例检索、案例引导荐参和模型训练命中数均保持零。
- [ ] MVP 不提供审核角色、审批页面或 PENDING_REVIEW → APPROVED 接口。

## 本票不包含

完整比赛展示层整合、跨模块 HG 最终放行、真实知识审核、Windows 发布包或算法质量评估。

## 独立验证

完成一次有效回放后关闭、生成报告/导出并提交案例；核对报告引用、免责声明、审计链、待审核列表、幂等提交及 APPROVED 检索/荐参零污染。再验证未回放关闭和未关闭提交均被阻断。

## TDD 与边界

- 使用 `/tdd`：是。
- SimulatorGateway：报告、关闭和案例模块不得直接调用；只消费不可变 ReplayResult。
- FaultTruth / 隐藏场景：报告、导出、审计、案例和 UI 扫描结果必须为零。
- APPROVED 案例：新案例固定为 PENDING_REVIEW；双重过滤继续生效。
