- [ ] 启动、页面切换、回放、报告、导出和案例提交期间无阻断性错误。

- [ ] 交付包仅通过 ReplayOrchestrator 使用 SimulatorGateway；诊断、检索、方向证据、候选生成和安全校验的调用计数仍为零。

## 独立验证

在目标 Windows 环境关闭网络，从全新解压目录一键启动并执行三轮计时演练；核对核心输出、运行时资产清单、调用边界、报告/导出免责声明、文档/截图/录像/应急材料和最终 HG 放行报告。

## TDD 与边界

- 使用 `/tdd`：否，本票以可重复打包、发布 preflight 和真实 Windows 人工 QA 为主；发现行为缺陷时回到所属功能边界使用 `/tdd` 修复。
- SimulatorGateway：发布包只允许 ReplayOrchestrator 调用。
- FaultTruth：隔离标签不进入运行时包；评估资产保持独立。
- 隐藏场景：作为受控模拟器资产交付，运行时应用只能持不透明引用和哈希。
- APPROVED 案例：只交付版本化 APPROVED 索引与独立 PENDING 列表，持续验证不互相污染。
