# 01 — TW-01 启动最小离线应用并显示任务与版本状态

**What to build:** 为 AA 工艺工程师提供可断网启动的最小 TuneWise 本地应用。应用从版本化资产读取固定演示身份和公共版本信息，创建处于 `CREATED` 的调机任务，并在统一阶段导航中显示当前阶段与后续闭环。运行时从第一票起排除训练/评估标签与隐藏场景内容，前端不得写死任务状态。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

## 规格追踪

- 规格章节：3、5、6、7、21.1–21.3、22.1、23.1。
- AC：AC-D2-01、AC-D2-02、AC-D3-03。
- HG：从首票建立 HG-07、HG-10、HG-13、HG-15 所需的运行时、资产和离线边界；本票只验收与最小骨架直接相关的证据。

## Acceptance criteria

- [ ] 在关闭外部网络的环境中启动应用，不请求云服务、在线模型、真实设备、MES 或 QMS。
- [ ] 页面显示固定身份 `demo-aa-engineer` / `AA_PROCESS_ENGINEER` / `AA工艺工程师`，不存在登录、注册、RBAC 或规则编辑入口。
- [ ] 应用从公共版本资产读取并显示版本信息，创建状态为 `CREATED` 的任务；当前阶段和完整后续阶段清晰可见。
- [ ] 状态来自后端任务对象和受控状态迁移，不由前端常量伪造。
- [ ] 缺失、版本不一致或哈希不匹配的公共资产使任务创建失败，并显示明确错误。
- [ ] 运行时依赖和打包边界不能导入或读取隔离的 FaultTruth 标签目录、训练/评估标签或隐藏场景内容。
- [ ] 最小应用在重复启动时给出相同的公共版本和初始任务语义。

## 本票不包含

CSV 导入、异常检测、根因排序、案例检索、参数候选、人工确认、SimulatorGateway 或回放。

## 独立验证

断网启动应用并检查固定身份、版本和 `CREATED` 阶段；对测试副本分别移除或篡改公共版本资产并确认拒绝；执行运行时依赖/资产扫描，证明隔离目录未被导入或访问。

## TDD 与边界

- 使用 `/tdd`：是，优先固定任务状态、资产读取、完整性和运行时隔离契约。
- SimulatorGateway：不装配、不调用。
- FaultTruth / 隐藏场景：建立运行时不可读的负向边界。
- APPROVED 案例：不涉及。

## Definition of done

- [ ] 本票新增测试及仓库原有测试全部通过。
- [ ] 不删除、跳过或弱化任何测试。
- [ ] 对应 AC/HG 具有可重复验证证据。
- [ ] 如引入新术语，已同步 `CONTEXT.md`；不得改变既有术语语义。
- [ ] 如发现规格冲突，已停止工作并上报，未修改八类冻结决策。
- [ ] 完成后仓库保持可运行和可演示。
- [ ] 本票覆盖的主流程不遗留 TODO、占位返回或假实现。
