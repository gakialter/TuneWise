# 02 — TW-02 导入预置 AA CSV 并验证版本化资产、Manifest、哈希与派生指标

**What to build:** 让 AA 工艺工程师能够通过确定性资产生成命令创建预置 AA 演示批次、Manifest 和不透明 `scenario_ref` 绑定，并在应用中导入该 CSV。有效输入形成只读快照、计算派生指标并进入 `DATA_IMPORTED`；字段、格式、版本或完整性错误被明确阻断。

**Blocked by:** 01 — TW-01 启动最小离线应用并显示任务与版本状态。

**Status:** ready-for-agent

## 规格追踪

- 规格章节：6、7、8.1–8.5、21.2–21.3、22.1–22.2、23.1–23.4。
- AC：AC-D1-01、AC-D3-04、AC-D4-01、AC-D4-02、AC-D4-06。
- HG：HG-07、HG-10、HG-15。

## Acceptance criteria

- [ ] 提供可重复执行的命令，以固定种子生成确定性演示 Batch、导入 CSV、DatasetManifest 和版本记录。
- [ ] 使用同一固定种子和相同版本重新生成时，可观测序列、规范化观测和 SHA-256 哈希完全一致。
- [ ] Manifest 将演示 CSV 的原始哈希、规范化观测哈希、canonicalizer/generator/schema/dataset 版本与不透明 `scenario_ref` 及其哈希绑定。
- [ ] `scenario_ref` 对应用不可解释、不可枚举；生成命令不把隐藏真值、内部系数或隐藏参数写入 CSV 或业务 Manifest 响应。
- [ ] 导入只接受冻结的 Measurement 可观测列和 AA 工站；派生的最差角、极差、标准差、控制限偏差及滚动指标由程序计算，CSV 不可覆盖。
- [ ] 有效导入创建 Batch、Measurements、控制限/参数约束/评价规则只读快照，并使任务进入 `DATA_IMPORTED`。
- [ ] 字段缺失、格式错误、非法额外标签、FaultTruth、调整后结果、Manifest/版本/哈希不匹配均使任务不推进。
- [ ] 规范化固定字段顺序、记录排序、精度、空值、编码和序列化；允许的换行或文件名差异不改变规范化哈希。
- [ ] 不得为通过校验修改、覆盖或重新生成用户已经导入的内容。

## 本票不包含

异常判定、模型训练或推理、案例索引、参数候选、人工确认和模拟回放。

## 独立验证

连续两次使用相同种子生成资产并比较规范化内容与哈希；导入有效演示 CSV；再分别验证字段缺失、格式错误、FaultTruth 列、派生字段覆盖、Manifest 篡改、CSV 篡改及 scenario_ref 绑定错误均被拒绝。

## TDD 与边界

- 使用 `/tdd`：是，确定性生成、规范化、哈希和外部输入边界需要测试先行。
- SimulatorGateway：不调用；资产生成可以使用隔离生成器，但运行时导入路径不得装配 Gateway。
- FaultTruth：只允许存在于隔离生成/评估元数据，导入边界显式拒绝。
- 隐藏场景：应用仅保存不透明引用及哈希；内容仍在运行时应用之外。
- APPROVED 案例：不涉及。
