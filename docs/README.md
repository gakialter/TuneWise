# TuneWise Documentation

本索引为公开仓库提供一层稳定、精简的文档导航。主 README 面向首次访问者；本页连接演示、验证、事实审计和最终比赛材料。内部路线图、生成脚本、归档产物与私有表单草稿不作为首页入口。

## 推荐阅读路径

1. 首次体验：先看 [Judge Guide](submission/judge-guide.md)，再按 [5-minute Demo Script](submission/demo-script-5min.md) 完成两个独立 Demo。
2. 验证证据：查看 [Engineering Validation](validation/engineering-validation.md) 与 [Aily Validation](validation/aily-v1-validation.md)。
3. 事实边界：查看 [Evidence Matrix](submission/40-final-evidence-matrix.md)、[Facts Audit](submission/40-final-fact-audit.md) 与 [LOROS Public-data Audit](research/loros-public-optical-dataset.md)。
4. 比赛材料：查看 [Final Competition Package](submission/TuneWise_40强_最终参赛方案_飞书导入版.docx)。
